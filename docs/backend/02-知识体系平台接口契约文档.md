# 知识体系平台接口契约文档

> 版本：V1.0
> 对齐产品文档：知识体系平台 PRD V3.6
> 本文档是前后端联调时的接口路径、字段、枚举和错误码依据。

## 1. 文档定位

服务对象分为两类：

- 管理端：内部运营后台，路径为 /api/v1/admin，当前仅管理员可用；
- 开放端：未来业务 App，只读知识库正式快照，路径为 /api/v1/open。

接口不返回草稿给开放端，也不提供独立知识点发布或独立知识关联发布。

## 2. 通用约定

### 2.1 请求和响应

- HTTPS、UTF-8、JSON；
- API 使用 camelCase；
- 时间使用 ISO 8601；
- 分页默认 pageNum=1、pageSize=10，最大 pageSize=100；
- 对外长期引用使用 canonicalId；
- ocrSignals、前置知识点等使用 JSON 数组；
- 正式查询响应必须返回 releaseVersion；
- 写请求需要携带 rowVersion，发生并发修改时返回 CONFLICT。

统一响应：

    {
      "code": "OK",
      "message": "success",
      "requestId": "req_01J...",
      "data": {},
      "meta": {
        "releaseVersion": "kb_1001.v2"
      }
    }

分页数据放在 data 中：

    {
      "list": [],
      "total": 0,
      "pageNum": 1,
      "pageSize": 10
    }

### 2.2 鉴权

管理端使用公司 SSO/OIDC 或受控会话 Cookie。当前版本统一映射为 admin。

开放端使用以下请求头：

- X-App-Key
- X-Timestamp
- X-Nonce
- X-Signature

签名使用 HMAC-SHA256。Secret 只保存在服务端。

## 3. 稳定枚举

| 字段 | API 值 |
| --- | --- |
| knowledgeType | concept、skill、problem_model、strategy、activity |
| gradeTermCode | g1_t1、g1_t2、g2_t1、g2_t2 |
| scope | core、supplement |
| knowledgeBaseStatus | pending、published、offline |
| knowledgeStatus | pending、published |
| relationStatus | pending、published |
| relationType | prerequisite、parallel、cross |
| releaseType | normal、rollback |
| jobStatus | queued、running、success、failed、cancelled |

不提供 disabled、active、stopped 等知识点或知识关联状态。

### 3.1 选项来源边界

不提供统一的 GET /api/v1/admin/options 接口。不同类型的下拉数据由所属业务接口提供：

- knowledgeType、scope、relationType 和状态是固定枚举，key 在本契约中定义，value 由前端文案或国际化资源展示；
- subjectCode、gradeTermCode 是教材域固定 key，V1 的展示文案为 math/数学、g1_t1/一年级上册等；
- textbookEditionCode 和 textbookEditionName 由教材版本接口返回；
- catalogNodeId 和目录名称由教材目录接口返回；
- 知识点候选由 GET /api/v1/admin/knowledge 的 keyword 搜索返回。

前端不自行维护业务 key，也不把目录、知识点和教材数据复制到本地字典。

## 4. 管理端接口

### 4.1 当前用户

    GET /api/v1/admin/me

响应示例：

    {
      "userId": "1001",
      "displayName": "知识运营管理员",
      "roles": ["admin"],
      "permissions": [
        "knowledge:read",
        "knowledge:write",
        "mapping:write",
        "relation:write",
        "release:write",
        "audit:read"
      ]
    }

V1 所有后台操作均由 admin 执行。Editor、Publisher 仅作为未来扩展角色，不出现在当前可用角色枚举中。

### 4.2 知识库

    GET    /api/v1/admin/knowledge-bases
    POST   /api/v1/admin/knowledge-bases
    GET    /api/v1/admin/knowledge-bases/{id}
    PATCH  /api/v1/admin/knowledge-bases/{id}
    DELETE /api/v1/admin/knowledge-bases/{id}

列表筛选：

- name；
- gradeTermCode；
- subjectCode；
- textbookEditionCode；
- status；
- pageNum；
- pageSize。

创建请求：

    {
      "name": "人教版2024数学一年级上册",
      "gradeTermCode": "g1_t1",
      "subjectCode": "math",
      "textbookEditionCode": "pep_math_2024_g1_t1",
      "rowVersion": 0
    }

响应至少包含：

    {
      "id": "1001",
      "name": "人教版2024数学一年级上册",
      "gradeTermCode": "g1_t1",
      "gradeTermName": "一年级上册",
      "subjectCode": "math",
      "subjectName": "数学",
      "textbookEditionCode": "pep_math_2024_g1_t1",
      "textbookEditionName": "人教版2024数学一年级上册",
      "status": "pending",
      "currentReleaseVersion": null,
      "knowledgeCount": 0,
      "updatedAt": "2026-08-09T10:00:00",
      "rowVersion": 1
    }

已发布或已下线知识库不能直接删除。只有没有正式版本且没有需要保留的草稿引用时才允许删除。

### 4.3 教材版本和目录

    GET /api/v1/admin/textbook-editions?subjectCode=math&gradeTermCode=g1_t1
    GET /api/v1/admin/textbook-editions/{editionCode}
    GET /api/v1/admin/textbook-editions/{editionCode}/catalog

教材版本列表响应：

    {
      "list": [
        {
          "key": "pep_math_2024_g1_t1",
          "value": "人教版2024数学一年级上册",
          "subjectCode": "math",
          "subjectName": "数学",
          "gradeTermCode": "g1_t1",
          "gradeTermName": "一年级上册"
        }
      ]
    }

目录节点响应：

    {
      "id": "node_1001",
      "parentId": "node_1000",
      "level": 2,
      "nodeType": "unit",
      "sourceKey": "g1_t1_u1",
      "sourcePath": "第一单元/准备课",
      "title": "准备课",
      "sortOrder": 1,
      "children": []
    }

目录来自教材源数据，V1 只返回教材根目录和单元，提供读取但不提供小节级映射、目录移动、删除、排序和独立知识点组接口。数据库可以保留更深层源数据，但不通过管理接口暴露。

### 4.4 知识库目录映射

    GET    /api/v1/admin/knowledge-bases/{id}/mappings
    POST   /api/v1/admin/knowledge-bases/{id}/mappings
    DELETE /api/v1/admin/knowledge-bases/{id}/mappings/{mappingId}

创建映射请求：

    {
      "catalogNodeId": "node_1001",
      "canonicalId": "10000001",
      "rowVersion": 3
    }

一个目录节点可以关联多个知识点。删除映射只取消当前知识库草稿中的关联，不删除知识点。映射不提供排序和下线字段。

### 4.5 原子知识点

    GET    /api/v1/admin/knowledge
    POST   /api/v1/admin/knowledge
    GET    /api/v1/admin/knowledge/{canonicalId}
    PATCH  /api/v1/admin/knowledge/{canonicalId}
    DELETE /api/v1/admin/knowledge/{canonicalId}
    POST   /api/v1/admin/knowledge/{canonicalId}/draft:revert

列表筛选：

- canonicalId；
- keyword；
- gradeTermCode；
- knowledgeType；
- scope；
- textbookEditionCode 或 knowledgeBaseId；
- status；
- pageNum；
- pageSize。

新增请求：

    {
      "knowledgeName": "100以内数的认识",
      "knowledgeType": "concept",
      "gradeTermCode": "g1_t1",
      "scope": "core",
      "ocrSignals": ["数数", "100以内"],
      "exerciseSignature": "按顺序数出物体数量",
      "rowVersion": 0
    }

新建接口不要求传入 canonicalId，服务端自动生成全局唯一的以 1 开头的 8 位纯数字字符串；导入接口要求提供符合规则的 canonicalId。生成后不可修改，删除后不可复用。

`canonicalId` 必须始终匹配 `^1\d{7}$`，接口 JSON 中按字符串传输。

列表响应至少包含：

    {
      "canonicalId": "10000001",
      "knowledgeName": "100以内数的认识",
      "knowledgeType": "concept",
      "gradeTermCode": "g1_t1",
      "scope": "core",
      "ocrSignals": ["数数", "100以内"],
      "exerciseSignature": "按顺序数出物体数量",
      "knowledgeBaseMappings": [
        {
          "knowledgeBaseId": "1001",
          "knowledgeBaseName": "人教版2024数学一年级上册",
          "textbookEditionCode": "pep_math_2024_g1_t1",
          "textbookEditionName": "人教版2024数学一年级上册"
        }
      ],
      "currentFormalVersions": [
        {
          "knowledgeBaseId": "1001",
          "releaseVersion": "kb_1001.v1"
        }
      ],
      "status": "published",
      "rowVersion": 2
    }

`knowledgeBaseMappings` 返回知识点当前已关联的知识库及其教材版本；同一知识点在同一知识库下映射多个目录时只返回一项。

currentFormalVersions 用于展示当前正式版本摘要。当前修订未进入任何知识库正式版本时，status 为 pending；已发布知识点再次编辑后，当前修订重新为 pending，但历史正式版本仍可读取。

知识点编辑不接收教材单元字段。教材关联通过知识库映射接口完成。

撤销草稿请求只允许恢复最近正式修订；首次创建且从未正式发布的草稿没有该入口。已发布或被引用的知识点不能硬删除。

### 4.6 知识关联

    GET    /api/v1/admin/relations
    POST   /api/v1/admin/relations
    GET    /api/v1/admin/relations/{relationId}
    PATCH  /api/v1/admin/relations/{relationId}
    DELETE /api/v1/admin/relations/{relationId}
    POST   /api/v1/admin/relations/{relationId}/draft:revert

列表筛选：

- canonicalId；
- knowledgeName；
- gradeTermCode；
- knowledgeType；
- knowledgeBaseId；
- status；
- pageNum；
- pageSize。

新建请求：

    {
      "canonicalId": "10000001",
      "prerequisiteCanonicalIds": ["10000002"],
      "parallelCanonicalIds": [],
      "crossCanonicalIds": [],
      "note": "",
      "rowVersion": 0
    }

响应按四组返回：

    {
      "relationId": "rel_1001",
      "canonicalId": "10000001",
      "knowledgeName": "100以内数的认识",
      "prerequisites": [
        {
          "canonicalId": "10000002",
          "knowledgeName": "1—10的读写"
        }
      ],
      "successors": [],
      "parallel": [],
      "cross": [],
      "currentFormalVersions": [],
      "status": "pending",
      "rowVersion": 1
    }

关系列表在上述分组字段之外，同时返回 `relations` 明细数组。分组数组元素包含
`canonicalId` 和 `knowledgeName`，管理端展示 `knowledgeName`，并使用
`canonicalId` 跳转到知识列表筛选。每个明细包含
`relationId`、`relationType`、`fromCanonicalId`、`toCanonicalId`、
`fromKnowledgeName`、`toKnowledgeName`、`operation`、`currentFormalVersions`、
`status` 和 `rowVersion`，供管理端对关系组执行编辑、删除和恢复。

后继关系由前置关系反向计算，不接受独立 successor 写入。系统拒绝自关联、重复关系和前置循环。已发布关系删除后，发布新知识库版本时从新快照移除，历史版本仍保留；不提供关系下线状态。

### 4.7 导入、任务和文件

    POST /api/v1/admin/imports
    POST /api/v1/admin/imports/{jobId}/commit
    GET  /api/v1/admin/jobs/{jobId}
    GET  /api/v1/admin/jobs/{jobId}/errors
    POST /api/v1/admin/jobs/{jobId}/retry
    GET  /api/v1/admin/files/{fileId}

Excel 主工作表名为 knowledge_points，表头固定为：

    canonical_id,type,name,grade_term,scope,pep24_path,ocr_signals,exercise_signature,prerequisites

其中：

- ocr_signals 和 prerequisites 是 JSON 数组字符串；
- canonical_id 是以 1 开头的 8 位纯数字字符串；新建接口的 ID 由服务端生成，Excel 导入仍需提供 ID；
- Excel 中 grade_term 使用教材文件中的中文值，导入校验后转换为接口使用的 gradeTermCode；
- pep24_path 只用于目录匹配建议；
- prerequisites 转为待确认的关系草稿；
- 确认提交前只写导入暂存表；
- 确认提交时整批事务写入；
- 单批最多 1000 行；
- 任一行违反唯一 ID、字段枚举、JSON 数组或关系引用规则时，整批不写入业务表。

任务响应：

    {
      "jobId": "1001",
      "jobType": "import",
      "status": "running",
      "totalCount": 1000,
      "successCount": 800,
      "failureCount": 10,
      "progressPercent": 81,
      "errorFileId": null,
      "canRetry": false
    }

### 4.8 发布、历史和下线

    POST /api/v1/admin/knowledge-bases/{id}/publish:validate
    POST /api/v1/admin/knowledge-bases/{id}/publish
    GET  /api/v1/admin/knowledge-bases/{id}/releases
    GET  /api/v1/admin/knowledge-bases/{id}/releases/{version}
    GET  /api/v1/admin/knowledge-bases/{id}/releases/{version}/diff
    POST /api/v1/admin/knowledge-bases/{id}/releases/{version}:rollback
    POST /api/v1/admin/knowledge-bases/{id}/offline

发布以知识库为边界，一次固化：

- 教材目录；
- 目录与知识点映射；
- 当前纳入的原子知识点修订；
- 当前纳入的知识关联修订。

发布成功生成该知识库的新 releaseVersion。正式版本不可修改。知识点或关系不提供单独发布接口。

回滚以历史正式版本为来源，生成新的 releaseType=rollback 版本，不覆盖历史版本，也不回写全局知识点草稿。

下线只改变知识库状态为 offline：

- 默认 App 查询不返回该知识库；
- currentReleaseVersion 和历史版本保留；
- 指定历史 releaseVersion 时仍可读取正式快照。

## 5. 开放端接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/v1/open/knowledge-bases | 按 gradeTermCode、subjectCode、textbookEditionCode 查询当前有效知识库 |
| GET | /api/v1/open/knowledge-bases/{id}/content | 读取当前正式快照 |
| GET | /api/v1/open/knowledge-bases/{id}/content?releaseVersion=... | 读取指定历史正式快照 |
| GET | /api/v1/open/knowledge-bases/{id}/knowledge/{canonicalId} | 读取正式知识点 |
| GET | /api/v1/open/knowledge-bases/{id}/relations | 读取正式关系 |

开放端返回内容至少包括：

- knowledgeBaseId；
- releaseVersion；
- 教材目录；
- 目录与知识点映射；
- 原子知识点属性；
- 知识点关系；
- 年级、学科和教材版本。

开放端不返回：

- 草稿；
- pending 状态的知识点或关系；
- 下线知识库的默认版本；
- 不在目标正式版本中的知识点。

## 6. 错误码

| HTTP | code | 说明 |
| --- | --- | --- |
| 400 | PARAM_INVALID | 参数格式或取值错误 |
| 401 | AUTH_FAILED | 未通过鉴权 |
| 403 | FORBIDDEN | 非管理员或 AppKey 无权限 |
| 404 | NOT_FOUND | 资源不存在 |
| 409 | CONFLICT | 乐观锁、唯一约束或版本冲突 |
| 422 | VALIDATION_FAILED | 业务规则校验失败 |
| 429 | RATE_LIMITED | 超出调用频率 |
| 500 | INTERNAL_ERROR | 未预期服务异常 |
| 503 | SERVICE_UNAVAILABLE | 服务未就绪 |

批量错误至少包含 rowNumber 或 objectId、field、reason、suggestion。错误响应不得返回 Secret、完整签名或敏感请求参数。
